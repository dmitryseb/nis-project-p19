## Сокращённый запуск

Демо проверяет запуск авторского примера на одном произвольно выбранном
наборе данных. Выбор регионов для основного исследования команда определит отдельно.

Нужны Conda, Bash, curl и unzip. Команда выполняется из корня командного
репозитория `dmitryseb/nis-project-p19`, в ветке `nis/checkpoint-1`:

```bash
bash scripts/run_demo.sh
```

Скрипт создаёт окружение из `environment.yml`, если его ещё нет, скачивает
и распаковывает данные демо при необходимости, выполняет первый раздел авторского
notebook и сохраняет график и числовую сводку. Если все 31 CSV уже на месте,
скачивание и распаковка пропускаются. Если есть только архив, он используется
повторно. Расчёт выполняется при каждом запуске.

Ожидаемый результат: 805 745 событий за 31 день, медиана 0.447381 с,
p95 ≈ 4.192305 с. [Подробная инструкция](docs/demo.md).

Если автоматическое скачивание не удалось, скачайте
[архив данных демо с Google Drive авторов](https://drive.google.com/file/d/1ah7nj5fyedMpOeaFgNVA7oMx3815D8BZ/view),
положите архив в `data/raw/R5.zip` относительно корня репозитория и повторите
`bash scripts/run_demo.sh`. Скрипт использует этот архив без повторного скачивания.
